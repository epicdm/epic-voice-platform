## 🔧 SIP Settings Explained

### What Each Field Means

**SIP Username (Extension)**:
- Numeric identifier for the SIP account (e.g., `3020`)
- Used to register with Magnus Billing SIP server
- Unique per agent

**SIP Password**:
- MD5 hashed password for authentication
- Auto-generated by Magnus Billing during provisioning
- Stored in database for LiveKit SIP trunk configuration

**SIP Domain/Server**:
- **voice.epic.dm** - Magnus Billing SIP server
- All agents register to this domain
- Handles both inbound and outbound calls

**SIP Port**:
- **5060** - Standard SIP port
- Used for SIP signaling (call setup/teardown)
- Not stored in DB (uses default)

**DID Number**:
- Direct Inward Dialing number (11 digits)
- Example: `17678189025` = +1 767 818 9025
- Assigned by Magnus Billing
- Used for outbound caller ID

**Assigned Phone Number**:
- Public-facing phone number (E.164 format)
- Example: `+17678189426`
- Routes inbound calls to this agent
- One phone number per agent (enforced)

## 🌐 Magnus Billing Integration

### API Endpoint
```
https://voice.epic.dm/mbilling/api
```

### SIP Server
```
voice.epic.dm:5060
```

### Authentication
- API Key: `8c0f89a45a4e485ab75babad914d33d0`
- Secret Key: `dc59cbbf25ab420ea9e6bff05479dc68`

### Provisioning Flow

When an agent is created:

1. **Magnus API Call**: `POST /mbilling/api/create/sip`
   - Creates SIP account with username (extension)
   - Generates random password
   - Returns SIP credentials

2. **DID Assignment**: `POST /mbilling/api/create/did`
   - Assigns DID number to account
   - Configures inbound routing

3. **Database Storage**: Store in `agent_configs` table
   - `sip_username`: Extension number
   - `sip_password`: MD5 hash
   - `sip_domain`: voice.epic.dm
   - `sip_server`: voice.epic.dm
   - `did_number`: Assigned DID

4. **LiveKit SIP Trunk**: Auto-configured
   - Inbound trunk for receiving calls
   - Outbound trunk for making calls
   - Routes to LiveKit room with agent
