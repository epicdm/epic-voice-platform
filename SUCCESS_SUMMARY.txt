┌──────────────────────────────────────────────────────────────────┐
│ 🎓 LESSONS LEARNED                                               │
└──────────────────────────────────────────────────────────────────┘

  1. Use official SDKs for complex protocols (protobuf)
  2. Transport layer MUST match (TCP vs UDP)
  3. Empty agent_name allows wildcard dispatch
  4. Create room before SIP participant
  5. CLI is valuable for establishing baseline
  6. Check response format (JSON vs plain text)
