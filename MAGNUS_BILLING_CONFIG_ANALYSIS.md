## 📋 Complete User Creation Flow

### **Step 1: Create Magnus User**

```php
$result = $magnusBilling->createUser([
    'username' => $trimmedFirstName . "_" . $did,  // e.g., "John_17678189025"
    'password' => $password,                        // 12-char random password
    'active' => '1',
    'firstname' => $firstname,
    'lastname' => $lastname,
    'email' => $_POST['email'],
    'typepaid' => '0',
    'prefix_local' => "*/1767/7,767/1767/10",      // Local dialing prefix
    'id_group' => '3',                              // User group ID
    'id_plan' => '34',                              // Rate plan ID
    'description' => 'EMA_Customer',
    'phone' => $phone,
    'mobile' => $phone,
    'id_offer' => '7',                              // Offer/package ID
]);
```

**What This Creates**:
- Magnus Billing user account
- **Automatically creates SIP account** (username = user username)
- SIP password is auto-generated by Magnus
- Returns user ID

---

### **Step 2: Create DID (Phone Number)**

```php
$create_did = $magnusBilling->create('did', [
    'did' => $did,                  // e.g., 17678189025
    'country' => 'Dominica',        // Country name
    'activated' => 1                // Active status
]);
```

**What This Creates**:
- DID number in Magnus Billing
- Links to country
- Activates the number

---

### **Step 3: Create DID Destination (Routing)**

```php
$create_destination = $magnusBilling->create('diddestination', [
    'id_user' => $id_user,                              // User ID
    'id_did' => $id_did,                                // DID ID
    'voip_call' => 1,                                   // Enable VoIP routing
    'id_sip' => $id_sip,                                // SIP account ID
    'idUserusername' => $trimmedFirstName . "_" . $did, // Username
    'destination' => 'SIP/' . $trimmedFirstName . "_" . $did,  // ⚠️ CRITICAL
    'priority' => 1                                     // Routing priority
]);
```

**⚠️ CRITICAL - This is NOT FreeSwitch syntax!**

The `'destination' => 'SIP/' . $username` is **Magnus Billing's internal routing format**, NOT FreeSwitch dialplan syntax.

**What This Means**:
- Magnus Billing handles the routing internally
- Format: `SIP/{username}` routes to SIP account
- **NOT Asterisk/FreeSwitch dialplan syntax**
- Magnus translates this to actual SIP routing

---

### **Step 4: Update SIP Account Settings**

```php
$result = $magnusBilling->update('sip', $id_sip, [
    'callerid' => $did,                      // Caller ID = DID number
    'voicemail' => '1',                      // Enable voicemail
    'voicemail_email' => $_POST['email'],    // Email for voicemail
    'voicemail_password' => substr($did, -4), // VM password (last 4 digits)
    'allow' => 'opus,g729,gsm,alaw,ulaw',    // Allowed codecs
]);
```

**What This Configures**:
- Outbound caller ID
- Voicemail settings
- Audio codecs for SIP calls
