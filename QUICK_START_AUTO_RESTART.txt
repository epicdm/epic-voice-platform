═══════════════════════════════════════════════════════════════════
🔧 WHAT HAPPENS AUTOMATICALLY
═══════════════════════════════════════════════════════════════════

When you click "Save Changes" on a DEPLOYED agent:

1. ✅ Database updated with your changes
2. 🛑 Old agent process stopped
3. 🔄 Environment refreshed
4. 🚀 New agent started
5. 📡 Connects to LiveKit Cloud
6. ✅ Loads fresh config from database
7. 🎉 Ready for calls with new settings!

All in ~5 seconds, automatically in background!

❓ FAQ
═══════════════════════════════════════════════════════════════════

Q: Does editing restart the agent?
A: YES! If deployed, it auto-restarts in ~5 seconds.

Q: What if agent is not deployed?
A: Changes are saved but not applied. Deploy manually to activate.

Q: Can I disable auto-restart?
A: Yes, but why would you? It's so convenient!

Q: What if restart fails?
A: Changes are still saved. Check logs, fix issue, manual deploy.

Q: Do active calls drop during restart?
A: No! Old instance handles active calls. New calls go to new instance.

Q: How long does restart take?
A: ~5-7 seconds total. Fast!
