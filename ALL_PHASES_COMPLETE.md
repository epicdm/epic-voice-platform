## 💻 How to Use

### For End Users

**Getting Started**:
1. Visit http://localhost:3001/
2. Click "Get Started"
3. Create free account
4. Go to Marketplace
5. Choose a template (e.g., "Customer Support Agent")
6. Click "Deploy Agent"
7. Customize settings
8. Start making calls!

**Managing Billing**:
1. Go to Dashboard → Billing
2. View current usage
3. Click "Upgrade to Pro" for more capacity
4. Enter payment details in Stripe
5. Subscription activates immediately

### For Developers

**API Integration**:
```bash
# 1. Generate API key
Visit: http://localhost:3001/dashboard/api-keys
Click: "Create API Key"
Copy: sk_live_...

# 2. Make API call
curl -H "Authorization: Bearer sk_live_..." \
     https://api.epic.ai/v1/agents

# 3. Create agent
curl -X POST \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"name":"My Agent","instructions":"Be helpful"}' \
  https://api.epic.ai/v1/agents
```

**SDK Usage** (Future):
```javascript
import EpicAI from '@epic.ai/sdk'

const client = new EpicAI({
  apiKey: process.env.EPIC_AI_API_KEY
})

const agent = await client.agents.create({
  name: 'Support Agent',
  instructions: 'Help customers with FAQs'
})

const call = await client.calls.create({
  agentId: agent.id,
  toNumber: '+15551234567'
})
```
