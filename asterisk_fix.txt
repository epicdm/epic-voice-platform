## QUICK FIX FOR ASTERISK 403 FORBIDDEN

The SIP call IS reaching Asterisk but getting rejected with 403 Forbidden.
This means the dialplan doesn't know how to route +17672958382.

### STEP 1: Add Test Dialplan

On your Asterisk server, edit: /etc/asterisk/extensions.conf

Add this at the bottom:

```
[from-livekit]
; Handle all LiveKit incoming calls
exten => _+.,1,NoOp(LiveKit call to ${EXTEN})
exten => _+.,n,Answer()
exten => _+.,n,Wait(1)
exten => _+.,n,Playback(hello-world)
exten => _+.,n,Wait(5)
exten => _+.,n,Hangup()

; Also match without + just in case
exten => _X.,1,NoOp(LiveKit call to ${EXTEN})
exten => _X.,n,Answer()
exten => _X.,n,Playback(hello-world)
exten => _X.,n,Wait(5)
exten => _X.,n,Hangup()
```

### STEP 2: Make Sure livekit Peer Uses This Context

**If using chan_sip**, edit /etc/asterisk/sip.conf:

```
[livekit]
type=friend
secret=werwqerwqrwq555
context=from-livekit
host=dynamic
insecure=invite,port
nat=yes
canreinvite=no
```

**If using pjsip**, edit /etc/asterisk/pjsip.conf:

```
[livekit]
type=endpoint
context=from-livekit
auth=livekit-auth
aors=livekit-aor
allow=ulaw,alaw,g722

[livekit-auth]
type=auth
auth_type=userpass
username=livekit
password=werwqerwqrwq555

[livekit-aor]
type=aor
max_contacts=1
```

### STEP 3: Reload Asterisk

```bash
asterisk -rx "dialplan reload"
asterisk -rx "sip reload"        # if using chan_sip
asterisk -rx "pjsip reload"      # if using pjsip
```

### STEP 4: Test Again

On testbed server:
```bash
cd /opt/livekit1
./test_sip_cli.sh
```

On Asterisk server, watch tcpdump:
```bash
tcpdump -i any port 5060 -n -A
```

You should now see:
- INVITE → 401
- INVITE with auth → **200 OK** (not 403!)
- Call connects
- You hear "hello world" message

### If Still Getting 403

Check which context the peer is actually using:
```bash
# chan_sip
asterisk -rx "sip show peer livekit" | grep Context

# pjsip
asterisk -rx "pjsip show endpoint livekit" | grep context
```

Make sure it says: Context: from-livekit

If it's a different context, either:
1. Change the peer config to use from-livekit
2. Or add the dialplan to the existing context
